# Experiment 2: Admin Panel for Post Composer

## Aim

To enhance the existing MERN Stack Post Composer by implementing an Admin Panel for managing users and posts.

---

## Objectives

* To develop an Admin Panel.
* To implement role-based access control.
* To manage registered users.
* To view and manage all posts.
* To provide separate User and Admin functionalities.
* To secure admin routes using JWT authentication.

---

## Technologies Used

### Frontend

* React.js
* React Router
* Axios
* HTML5
* CSS3
* JavaScript

### Backend

* Node.js
* Express.js
* JWT
* bcrypt

### Database

* MongoDB Atlas
* Mongoose

---

## About the Program

This experiment extends the existing **Post Composer** application by adding an **Admin Panel**.

The Admin Panel allows administrators to view registered users, view all posts, manage posts, and monitor application activity. Role-based authorization ensures that only authorized administrators can access admin features.

---

## Admin Features

* Admin Login
* Admin Dashboard
* View All Users
* View All Posts
* Manage Posts
* Delete Users
* Delete Posts
* Secure Logout

---

## User Features

Users can:

* Register and Login
* Create Posts
* Edit Posts
* Delete Posts
* View Their Posts
* Schedule Posts

---

## Role-Based Access

| Role  | Access                     |
| ----- | -------------------------- |
| User  | Manage own posts           |
| Admin | Manage users and all posts |

---

## Learning Outcomes

After completing this experiment, the student will be able to:

* Create an Admin Panel using React.
* Implement JWT-based authentication.
* Implement role-based authorization.
* Manage users and posts.
* Create protected admin routes.
* Integrate frontend, backend, and MongoDB.

---

## Conclusion

The Admin Panel successfully extends the Post Composer application by providing administrators with secure management of users and posts using the MERN Stack.
